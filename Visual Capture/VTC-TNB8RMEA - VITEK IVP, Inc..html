    VTC-TNB8RMEA

    Transcendent 8MP Indoor/Outdoor WDR IP Motorized Turret Camera with Matrix IRs

    • 1/2.8” 8.0 MegaPixel [4K] CMOS Image Sensor
    • NDAA Compliant
    • Also Available in Charcoal:
      • (VTD-TNB8RMEAB)
    • 8MP (3840 × 2160) [1~20fps], 6MP (3072 × 2048 ), 5MP (2592 × 1944), 720P (1280 × 720), D1, CIF, 480 × 240 [1~30fps]
    • 2.8~12mm Motorized Varifocal Lens
    • Matrix IR (up to 165’ IR Range)
    • True Wide Dynamic Range (120dB)
    • True Mechanical Day/Night function by ICR
    • XD-DNR (3D & 2D-DNR) Noise Reduction
    • Programmable Analytics: Region Intrusion Detection, Scene Change Detection, Line Crossing
    • H.265+ / H.265 / H.264+ / H.264 / MJPEG
    • MicroSD Card Slot for Local Recording (Up to 256GB)
    • 1 Ch. Audio In*
    • Remote Viewing via CMS, Edge in IE Mode, and iOS & Android Apps
    • ONVIF Compliant
    • IP67 Weather Resistance
    • Included Wall Mount, Optional Junction Box (VT-TJB08) Available (See Other Mounting Options Below)
    • 12VDC & PoE (Power over Ethernet) Operation
    • 3-Year Warranty

    Specifications

    Image Sensor 1/2.7” 8.0 Megapixel [4K] Progressive Scan CMOS

    Image Size 8 MegaPixel (3840 × 2160)

    Resolution Up to 20fps @ 8MP (3840 × 2160), 6MP (3072× 2048 ),5MP (2592 ×1944 ), 720P (1280 × 720), D1, CIF, 480 × 240

    Min. Illumination 0.02 lux @ F1.6, AGC ON; 0 lux with IR, 0.01lux@F1.2, AGC ON; 0 lux with IR

    Electronic Shutter 1s ~ 1 / 100000s

    Lens 2.8~12mm Motorized Varifocal Lens

    Day/Night True Day/Night by ICR

    IR LEDs 2 Matrix IRs

    IR Distance Up to 165‘

    Video Compression H.265+ / H.265 / H.264+ / H.264 /MJPEG

    Audio Compression G.711A / G.711U

    Main Stream 8MP [4K] (1~20fps) / 6MP / 5MP / 720P / D1 / CIF / 480 x 240 (1~30fps) 

    Sub Stream, Third Stream 60Hz: 720P/D1/480 × 240(1~30fps), 60Hz: D1/CIF/480 × 240 (1~30fps)

    Bit Rate / Type 64 Kbps ~ 12 Mbps / VBR + CBR

    WDR 120dB Super WDR

    DNR 3D-DNR

    Backlight Compensation Yes

    Highlight Compensation Yes

    Defog Yes

    Image Setting ROI, Saturation, Brightness, Chroma, Contrast, Sharpen, NR; Adjustable through client software or browser

    Analytics Region Intrusion, Scene Change Detection, Line Crossing, Video Blur, Video Color Cast Detection

    Smart Alarm Motion Detection, SD Card Error, SD Card Full

    General Functions Watermark, IP Filter, Video Mask, Illegal Login Lock

    Region of Interest (ROI) Each ROI to be configured separately

    Hardware Reset Yes

    Analog Video Output No

    Audio 1 Ch. Audio In + Built-in Mic*

    Local Storage Built-in Micro SD card slot up to 256GB

    Remote Viewing CMS / Web Browser / Mobile (iOS/Android)

    Supported Browsers Internet Explorer, Chrome and Firefox with IE Tab, and Edge in IE mode 

    Connection Protocol ONVIF

    Weather Resistance IP67 Weather Resistance

    Power Input 12VDC / PoE

    Power Consumption (12VDC) 350mA (IR Off) / 850mA (IR On)

    Power Consumption (PoE) < 10W

    Working Environment -4~140° / < 95% Humidity

    Weight 24.34oz / 1.52lb (690g)

    Dimensions 8.68 × 3.15 × 2.78” (220.5 × 80.1 × 70.5mm)

    *Please research local, state, and federal law regarding the implementation and use of audio surveillance
